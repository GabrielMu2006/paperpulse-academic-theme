# Design system

PaperPulse Academic translates visual roles from the real PaperPulse macOS app
rather than copying its window layout or product behavior.

## Principles

- **Midnight shell:** Dark mode uses navy and aubergine planes with a restrained
  translucent hierarchy. Light mode uses warm off-white and parchment planes.
- **Paper for reading:** editor and reading planes are calm and high-contrast.
  Saturated gradients never sit behind long-form text.
- **Pulse with restraint:** red, magenta, and purple identify selection,
  primary action, progress, and focus. User Accent Color remains authoritative
  for ordinary interactive roles.
- **Gold is personal:** warm gold is limited to favorite/bookmark emphasis.
- **Compact scholarship:** system fonts, readable long-form line height, a
  6/8/10/12 px radius scale, quiet borders, and low shadows preserve density.

## Scheme roles

Dark uses `#05030f`, `#080d29`, and `#290538` as the brand lineage, tuned into
readable semantic planes. Warm paper derives from `#fff7e8` and `#ffeeda`.
Light uses parchment-neutral planes with wine/plum text and low-saturation
accent support; it is not generated by color inversion.

Obsidian's `--accent-h`, `--accent-s`, and `--accent-l` feed links, focus,
selection, active controls, and the Dashboard contract. The PaperPulse
red→magenta→purple gradient is reserved for small identity bars and selected
emphasis.

## Editor visibility

Editing affordances use dedicated paper-aware roles instead of inheriting the
user accent directly. The insertion caret is two pixels wide and uses a dark
ink color on both warm-paper schemes. Active Markdown and math source use a
restrained plum with text-level contrast, while inline and fenced code receive
explicit backgrounds, borders, and text colors. Reading-mode rendering remains
unchanged.

Properties shown above the editor share that same paper context. Their heading,
icons, labels, values, dates, list pills, and add-property action therefore
resolve from paper ink/secondary roles instead of the surrounding application
shell. Label and value fields use quiet paper-toned hover/focus fills rather
than dark shell form controls.

## Material and fallbacks

Glass uses a solid color first, with transparency/blur only when supported.
Reduced-transparency and increased-contrast media queries restore opaque
surfaces and stronger borders. Forced colors uses system colors. Print removes
the shell, shadows, and translucent material and prints black text on white.

## Optional Style Settings

CSS metadata exposes glass strength, paper temperature, accent intensity,
radius, shadow, and density. Defaults are the complete supported theme; no
plugin is required. Resetting all controls removes their body classes and
returns exactly to the default token set.
