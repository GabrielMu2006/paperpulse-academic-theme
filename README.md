# PaperPulse Academic

**English** | [简体中文](README.zh-CN.md)

PaperPulse Academic is a complete Obsidian theme for focused reading, research,
and long-form writing. It translates the PaperPulse macOS visual language into
a quiet academic workspace: midnight navy and aubergine in Dark mode, warm
paper surfaces in Light mode, and restrained red–magenta–purple emphasis.

Light mode is designed independently rather than generated by inverting the
Dark palette. Both schemes follow Obsidian's semantic variables and the user's
Accent Color.

> Current version: **[1.0.0](https://github.com/GabrielMu2006/paperpulse-academic-theme/releases/tag/1.0.0)**<br>
> Minimum Obsidian version: **1.13.6**<br>
> Primary verified environment: **Obsidian Desktop on macOS**

## Highlights

- Complete Light and Dark schemes for the Obsidian shell and reading surfaces.
- Warm, low-saturation editor and reading planes intended for sustained work.
- Coverage for sidebars, tabs, ribbon, menus, command palette, modals, notices,
  settings, forms, Properties, Bases, Canvas, and Graph.
- User Accent Color support for links, focus, selections, and primary controls.
- Optional Style Settings controls without making Style Settings a dependency.
- A documented visual contract for the independent Academic Dashboard plugin.
- Reduced-motion, reduced-transparency, increased-contrast, forced-colors, and
  print fallbacks.
- CSS only: no JavaScript, telemetry, network requests, remote fonts, remote
  images, runtime dependencies, or automatic Vault changes.

## Installation

### From a GitHub release

After a release is published, download either the release archive or both
`manifest.json` and `theme.css` from the same release.

Create the following folder inside your Vault and place the two files in it:

```text
<Vault>/.obsidian/themes/PaperPulse Academic/
├── manifest.json
└── theme.css
```

Open **Settings → Appearance → Themes**, then select **PaperPulse Academic**.
The theme never selects or enables itself automatically.

### From source

Clone or download this repository, then copy the root `manifest.json` and
`theme.css` into the same folder shown above. Use files from one commit only;
mixing files from different versions is unsupported.

### Updating

Replace the installed `manifest.json` and `theme.css` with files from the same
new release, then reload Obsidian. Your Accent Color and optional Style Settings
choices remain managed by Obsidian and are not stored in this repository.

### Removing

Choose another theme in **Settings → Appearance**, then remove
`<Vault>/.obsidian/themes/PaperPulse Academic/`. Removing the theme does not
change notes or other Obsidian settings.

## Design language

### Dark scheme

Dark mode uses a near-black research shell with navy and aubergine depth.
Saturated pulse colors are limited to identity, selection, focus, progress, and
small interactive emphasis; they are not placed behind long-form text.

### Light scheme

Light mode uses warm off-white and parchment surfaces with wine and plum text.
Its hierarchy is tuned separately for paper-like reading instead of mirroring
or inverting Dark mode.

### Optional Style Settings

The CSS includes metadata for the Style Settings community plugin. When that
plugin is installed, it can adjust:

- glass strength;
- paper temperature;
- accent intensity;
- corner radius;
- shadow depth; and
- interface density.

Style Settings is optional. The default token set is the complete supported
theme, and resetting all controls returns to those defaults.

## Academic Dashboard integration

PaperPulse Academic can style the independent Academic Dashboard plugin through
its public `--academic-dashboard-*` custom properties. The integration is
scoped to `.academic-dashboard-view` and does not depend on Dashboard component
classes, DOM order, data attributes, or GridStack internals.

Academic Dashboard is not required. When it is absent, the theme remains fully
functional; when another theme is active, Dashboard falls back to Obsidian's
semantic variables.

## Compatibility and accessibility

The acceptance matrix covers Obsidian Desktop 1.13.6–1.13.7, Default Light and
Dark behavior, Accent Color, 100–200% zoom, keyboard focus, reduced motion,
reduced transparency, increased contrast, forced colors, and print. Other
desktop operating systems may work but are not yet part of the verified
acceptance platform.

The theme keeps interaction states distinguishable by more than color, restores
opaque materials where transparency is reduced or unavailable, and uses system
colors in forced-colors mode. See the
[compatibility matrix](docs/compatibility-matrix.md) for the current test scope.

## Privacy and safety

The public runtime consists only of `manifest.json` and `theme.css`. The theme:

- cannot read or write notes;
- cannot access credentials or plugin data;
- does not make network requests;
- does not load remote fonts or images;
- does not collect analytics or telemetry; and
- does not modify `.obsidian` configuration or enable itself.

Review the source before installation if your Vault contains sensitive data.

## Development and verification

No package manager or build step is required. A POSIX shell and Python 3 are
enough for the repository checks:

```sh
./scripts/check-theme.sh
./scripts/contrast-audit.py
./scripts/package-theme.sh
```

Before a release, also verify the full compatibility matrix in a real Obsidian
Vault. Run the packaging script twice and compare SHA-256 output to confirm that
the archive is deterministic.

The release archive contains only:

```text
PaperPulse Academic/
├── manifest.json
├── theme.css
├── LICENSE
```

## Contributing

Issues and focused pull requests are welcome after the public repository is
available. Please include the Obsidian version, operating system, color scheme,
Accent Color, zoom level, affected surface, and a screenshot made with synthetic
content. Do not attach a private Vault, plugin settings, credentials, or images
that reveal personal notes.

Changes should preserve both color schemes, accessibility fallbacks, the public
Academic Dashboard contract, and the theme's no-network/no-JavaScript boundary.
